Changing a game

  • Settings such as lives, speeds and colours are constants near the top of each file: change a number and press Run.
  • Every run starts on a freshly reset C64, so nothing is left over from the last one.
  • Pause above the screen, then Step to follow the game one instruction at a time. The memory viewer shows its variables change: try Zero page.
  • Labels are not case-sensitive: SCORE and score are the same name. A branch reaches 127 bytes; to go further, branch over a JMP.
  • The File menu saves your version, as source or as a .prg that runs in other C64 emulators: LOAD"GAME",8,1 then SYS 2064.
